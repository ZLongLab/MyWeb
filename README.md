# 有间小站

一个可以本地打开的中文个人网站，主导航为首页、作品、文章、关于，工作台和本地便签从页脚进入。作品和文章各分列表与详情，共 8 个页面。支持全站搜索，当前用于预览和继续完善，尚未上线。

源码与版本历史保存在 GitHub 公开仓库 [ZLongLab/MyWeb](https://github.com/ZLongLab/MyWeb)，可供阅读和审核。仓库公开不等于网站已经上线，目前未启用 GitHub Pages。基准标记为 `baseline-2026-10-25`，后续保存和恢复方式见 [版本恢复说明](版本恢复说明.md)。

## 打开网站

- 最简单：双击 `index.html`，浏览器会直接打开首页。
- 推荐：已安装 Node.js 时，双击 `启动预览.cmd`。启动成功后会自动打开浏览器，地址默认为 `http://127.0.0.1:4173`。保留终端窗口，按 `Ctrl+C` 停止预览。
- 也可以在这个文件夹打开终端，运行 `npm start`，再手动打开上述地址。不需要执行 `npm install`。

预览只监听本机的 `127.0.0.1`，其他设备不能通过局域网访问。如果端口已被占用，可在 PowerShell 中运行：

```powershell
$env:PORT = '4174'
npm start
```

然后访问 `http://127.0.0.1:4174`。只对当前终端生效；结束后可以关闭终端，或运行 `Remove-Item Env:PORT`。

## 换成自己的内容

1. 用文本编辑器打开 `assets/site-data.js`，按照文件中的注释修改称呼、身份、简介和邮箱等资料。当前署名为 ZL，身份为计算机学生；站名保留“有间小站”。
2. “联系我”统一进入关于页的联系区。当前提供真实 GitHub 账号；没有任何有效联系地址时才显示待公开提示。填写有效邮箱后显示独立的“发送邮件”按钮。社交地址的 `locations` 可限定 home / footer / contact 位置。
3. 作品内容集中在 `assets/projects-data.js` 中，已放入 RecallAI、DocumentAssistant、Folia Android 适配和本站。用途、技术与版本说明根据本机项目文档整理；Folia 标明基于开源项目的适配。`featured: true` 控制首页精选，`image` 维护预览图，`sections` 可补充段落、列表和小节图片，`articleId` 可关联开发手记；其他作品通过“全部作品”浏览。分类筛选由 `assets/projects.js` 处理，独立详情页 `project.html` 由 `assets/project.js` 渲染。
4. 文章内容集中在 `assets/articles-data.js` 中。参考已有对象，修改标识、标题、分类、日期、摘要和正文。每篇文章需要不同的标识。首页、列表和搜索共用 `assets/content.js` 的日期排序；阅读时间可手写，省略或留空时按正文约 320 字/分钟向上取整，最少 1 分钟。
5. 页面文字和布局分别在 `index.html`、`projects.html`、`project.html`、`articles.html`、`article.html`、`guestbook.html`、`about.html` 中。当前共享视觉在 `assets/site-theme.css`，首页布局在 `assets/home.css`，背景在 `assets/background.css` 与 `assets/page-background.svg`，详情导航在 `assets/navigation.css`。基础样式 `assets/styles.css` 继续加载；旧 warm 与 Bento 主题已停止引用，避免多层覆盖。

修改文件并保存后，刷新浏览器即可看到更新。无需编译，也无需安装依赖。

## 纸色、夜色与离线使用

- 顶栏太阳／月亮按钮切换纸色与夜色。选择仅保存在当前浏览器，键为 `myweb_theme_v1`；手动选择优先。没有保存选择时，按本地时间在 20:00–次日 06:00 默认夜色，其余时间默认纸色。页面首次绘制前确定主题；存储被禁用时仍可在当前页面切换。
- 动效放在 `assets/motion.css` 与 `assets/motion.js`，主题放在 `assets/night.css` 与 `assets/theme-controls.js`。跨页过渡是浏览器渐进增强，不支持时使用普通链接跳转。系统开启“减少动态效果”后，入场、滚动、门扇、颜色过渡、平滑滚动与跨页过渡全部关闭，内容直接可见。
- 用固定的本地预览地址或 HTTPS 打开，首次完整联网加载后会缓存 48 个运行资源，断网仍可浏览页面和本地搜索。缓存只包含 8 个页面、脚本、样式、图片和安装图标，不包含维护文档、备份、外链或浏览器便签数据。更新时先使用网络，失败才读取缓存；便签仍需另行导出备份。
- 浏览器确认支持安装并发出安装事件时，页脚才显示“安装小站”。安装由浏览器处理；自动化验收没有实际安装到操作系统，也没有验证手机或 Safari 安装。无安装入口时可继续正常使用。
- `file://` 双击打开保留浏览、搜索、主题和便签功能，不加载 manifest、不注册离线服务，也不提供安装。不同协议、地址和端口的主题与便签存储彼此独立。
- 修改运行资源后，记得同步维护 `server.mjs` 的服务白名单与 `sw.js` 的离线清单；发布新离线版本时更新 SW 缓存版本。新缓存完整下载失败时不会强制替换已启用版本；旧页面关闭后新版本再接管。
- 本轮按 0.14「体验版」完成。截图拼贴、窗口画框、深色精选带等属于 0.15；搜索分组高亮、RSS、404 与部署清单留在开放前阶段，尚未实现或上线。

## 阅读文章与笔记

- 点击导航中的“文章”，进入 `articles.html`；首页也有“全部文章”入口。
- 列表支持关键词搜索和分类筛选，处理过程在当前浏览器本地完成，不会将搜索词上传到服务器。
- 首页与文章列表先按日期从新到旧排序，同日保持原数据顺序；“继续阅读”先选同分类或共享标签的文章，再用最新文章补足两篇。
- 点击文章卡片打开详情。每篇文章使用独立地址，例如 `article.html?id=hello-world`，可以保存或复制这个地址。
- 直接双击 `index.html` 后也可以正常浏览文章，详情页支持 `file://` 本地路径；使用预览服务器时，对应地址为 `http://127.0.0.1:4173/article.html?id=hello-world`。
- 文章由本地文件维护。新增或修改内容后，在浏览器中刷新即可。
- 从列表进入详情后，通过面包屑或返回按钮可恢复原筛选、关键词与滚动高度；继续阅读也沿用原列表位置。内容高度变化时恢复到可达高度，顶部导航仍打开完整列表。位置仅记在当前标签页；存储被禁用时保留普通导航。

## 全站搜索

- 导航中的“搜索”或 `Ctrl+K` / `Cmd+K` 会打开搜索面板，覆盖作品、文章全文和主要页面。
- 搜索在浏览器内完成，不会上传关键词。结果直接进入对应文章或作品详情。
- 文章分类由文章数据自动生成；增加文章或项目后，全站搜索会在刷新后一起更新。
- 关闭再打开搜索时保留上次输入和结果，并全选输入文字。搜索词使用 `sessionStorage` 保留在当前标签页，打开详情后也能继续上一轮搜索；存储不可用时仍保留当前页面内的输入。

## 随手便签（本地）

- 从各页页脚的“随手便签（本地）”进入 `guestbook.html`。便签只保存在当前浏览器，不发送给站主，也不跨设备同步；未接入公共留言后台，原有存储键和数据格式保持一致。
- 页面定位为本地随手便签／灵感草稿箱，可保存昵称与内容、刷新查看、逐条确认删除，以及导出和导入 JSON 备份。
- 使用 `localStorage`，键名为 `myweb_guestbook_v1`。清理浏览器网站数据会移除留言；重要内容请先导出。
- 推荐用 `启动预览.cmd` 打开的固定地址使用留言。同一浏览器中的 `file://`、`http://127.0.0.1:4173` 与其他端口各有独立存储；浏览器限制本地文件存储时，页面会提示使用预览服务。
- 导入使用本站版本 1 的备份格式，与原有导出文件兼容。完整校验后合并到现有便签：相同编号且内容一致的记录跳过；编号冲突、格式异常、合并后超过 100 条或存储不足时，整次导入失败并保留现有数据。导入文件最多 1,200,000 字节，JSON 文本最多 300,000 字符。
- 存储不可用、空间不足或已存数据格式异常时，会明确报错，不会显示“已保存”或覆盖异常数据。同源标签页变化仍会刷新，导入完成写入前会重读最新数据；这不等同于数据库事务或跨标签页并发写入保证。

## 当前范围

- 所有页面、样式和脚本均在本地文件中，没有接入云服务、统计跟踪或外部 API；点击项目源码外链时才会前往 GitHub。
- 没有业务后端、数据库、登录系统或表单收件服务；填写邮箱后，邮件入口使用设备上的邮件应用。
- 本地预览服务器只提供这 8 个 HTML 页面和指定的页面资源，不会公开 README、启动脚本或其他工作区文件。
- 本版没有发布到互联网，也没有配置域名。以后确定内容后，可以部署到静态网站托管平台。
