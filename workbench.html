04 / COLOPHON

关于本站

这个小站的制作方式，以及数据留在哪里。

制作方式
原生 HTML、CSS 与 JavaScript 静态页面，不依赖框架或外部运行库；本地预览可使用本机服务。内容随本地文件维护，目前尚未启用公开托管。
字体与颜色
优先使用本机的中文无衬线与衬线字体，缺少时回退到系统字体。暖纸底、暖沙色带，搭配松针绿、暖陶土、琥珀金与青瓷灰蓝，没有在线字体请求。
搜索与便签
搜索在浏览器内完成，不上传关键词。随手便签只保存在当前浏览器，不发送给站主；重要内容可在便签页导出 JSON 备份。
版本与交流
源码使用公开仓库保存版本，可供阅读和审核；代码备份不包含浏览器里的便签。项目交流入口放在关于页的联系区。
