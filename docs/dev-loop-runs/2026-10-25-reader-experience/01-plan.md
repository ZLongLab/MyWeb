# 实现顺序

1. 共用资料配置与社交入口：统一外链箭头，限定 GitHub 账号在联系区展示，避免首页堆叠操作。
2. 截图预览：独立原生 dialog 模块，仅首页、作品详情加载；图片按钮与作品阅读链接各自独立，避免交互嵌套。
3. 作品目录：从带标题的 sections 自动生成，使用原生锚点，短内容不生成空目录。
4. 内容：依据 DocumentAssistant README 和归档检查文档写作，写清规则分类、确认复制与源码/安装包的版本差异。
5. 验收：脚本语法、暂存差异检查、390/1440 宽度交互，验证键盘开关、缩放、目录、关联文章、联系与搜索入口。
6. 文档、版本号与私有仓库：提交后核对远端哈希与私有状态，保留 baseline-2026-10-25。

主要风险与处理：原首页整行链接包含截图 → 拆分独立阅读链接和图片入口；dialog 与搜索冲突 → 遵循现有单一模态规则；截图加载失败 → 明确提示并保留原图入口；目录跳转 → 保留 query 参数及列表来源。
