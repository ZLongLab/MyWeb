## 本轮交付

1. 8 个页面接入纸色／夜色，载入前确定主题，手动选择持久保存并跨同源标签页同步。没有选择时按本地时间默认；存储受限时当前页仍能切换。夜色同步覆盖表单、弹窗、截图预览与各页细节，截图亮度为 96%。
2. 同源跨页使用原生 View Transitions，品牌单独命名；普通链接、详情参数和返回规则继续使用。浏览器不支持时保持正常跳转。
3. 首屏标题、简介、按钮与近况依次入场；只保留一处荧光笔高光。全站下方区块进入视口后浮现，页面内定位和键盘聚焦立即显现目标，避免内容被动画隐藏。
4. 页头改用同形内联 SVG，门扇可响应悬停及键盘焦点。系统减少动态效果时关闭所有动画、过渡及平滑滚动，直接显示内容。
5. 增加本地 manifest、192／512 图标与严格白名单的离线缓存。网络优先，离线回退，缓存查询归一化；不强制替换旧版打开的页面。仅收到真实浏览器安装事件时提供安装按钮。
6. 补齐链接与筛选按钮点击区域，更新 README、工作台记录、恢复说明与服务白名单。没有新增运行依赖、框架或构建流程。

## 使用与维护

- 运行 `npm start`，打开 `http://127.0.0.1:4173`。顶栏太阳／月亮切换外观；双击文件打开同样可用主题与搜索。
- 本机预览或 HTTPS 完整加载一次后，离线缓存可用。安装入口由浏览器判断；file:// 不注册 SW、不加载 manifest、不显示安装。
- 便签仍是原有 `myweb_guestbook_v1` 数据，主题另用 `myweb_theme_v1`。源码备份及离线缓存都不能替代便签 JSON 导出。
- 运行资源清单必须同时维护 server.mjs 与 sw.js。公开仓库没有启用 Pages，预览服务也不提供 docs、备份或研究文件。
