## 验收要求

- 原生静态、无框架、无构建；没有新增网站运行依赖或外部资源请求。
- file:// 可读、可搜、可切主题；该模式不请求 manifest 或注册 Service Worker。
- 320 / 390 / 768 / 1024 / 1440 宽度无溢出，主题切换刷新后保留，存储不可用时仍可切换。
- prefers-reduced-motion 关闭所有入场、滚动、门扇、主题过渡与跨页过渡；内容直接可见。
- 正常链接与键盘搜索、详情返回、截图与便签等已有功能保持。
- SW 仅处理明确允许的同源运行资源；不缓存 docs、备份、研究记录或外链。
- PWA 注册、离线恢复与图标检查不等于完成操作系统级安装，不宣称未实际验证的设备支持。

## 工作分工

主题代理只负责 night.css/theme-controls.js；动效代理只负责 motion.css/js；PWA 代理只负责 manifest、sw、pwa.js/css、两档图标。主代理负责 HTML 接入、初始化、白名单、集成审查、浏览器验收与版本保存。
