# 1.5.2「边界修复」交付记录

交付日期：2026-10-28。验收在10月27日晚至28日完成。代码基线：1.5.1 / `b42b92f`，恢复标记：`boundary-1.5.2`。

本轮只处理桌面首屏光晕、水印与页头三个边界问题。没有新页面、运行文件、依赖或外部运行请求；保留其他1.5布局、颜色变量、文章16px／2.1／720px、动效与个人内容结论。

## 1 · 光晕出盒

桌面≥1024px时，`.home-opening::before`的左右定位改为`calc(50% - 50vw)`，画布宽度实测为1280／1440／1920px，摆脱1200px内容盒。移除桌面横向mask，只保留原有纵向渐隐。

径向渐变改为`ellipse 38% 64% at 40% 32%`、100%处透明，季节色仍为12%。水平最宽截面从画布2%延伸到78%，所以局部色场在到达屏幕左右边缘之前已经透明。纸／夜、三档宽度的开关光晕对照确认：视口边缘像素受该局部色场影响为0。

100vw包含滚动条宽度时，局部伪元素会在页面边缘各多出约5px。采用**仅首页全宽main的`overflow-x: clip`**处理；裁切面是页面视口，仍允许色场经过内容容器左右边线。没有对1200px首屏容器裁切，也没有给body／html隐藏溢出来掩盖布局问题。三档实测均无横向滚动条。

body两团全站光晕、夜色星点与原有纸纹没有修改；二者叠加后的容器边线采样如下。

## 2 · 水印收界

选择**水印独立定位收界**，不对窗口舞台整体加overflow裁切：水印改为280×280px，舞台内左24px、上72px，放回主窗口后方。三档宽度下水印边框均完全位于384px高的舞台内，屋顶斜线不再进入色卡／印章区域。

透明度保留0.07，没有降到0.05。窗口、便签与舞台的overflow保持原样，截图与便签的原投影仍存在；页面级clip只在视口边缘生效，远离这些投影。

## 3 · 页头同底

桌面顶部状态为透明背景、无backdrop模糊、透明底边框，与页面纸色和光晕同底。透明边框保留原1px占位，不再显示板状底色。

沿用现有粘性状态切换：滚动超过24px后，页头才出现当前纸色85%半透明底、blur(8px)与1px发丝线；高度仍为88→64px，24px补偿保持文档占位不变。没有新增状态切换功能或修改motion.js。

纸／夜各14页核对顶部外观；可滚动页核对滚动状态。404在1000px高的桌面视口中滚动范围为0，按透明顶部状态核对。首页1920px真实滚动300px后已截图目检；文章定位首段距视口顶部92.19px，页头底部64px，阅读进度线仍位于页头上方。

## 4 · 容器边线像素对照

工具链沿用本机Chrome／Playwright截图、浏览器Canvas解码PNG，与既有实际合成背景对比度抽样相同。采样y取首屏竖直中点（本轮为420px），左右边线各取x−2与x+2的**实际8位RGB像素**。为避开文字与物件，取样帧临时隐藏前景copy／showcase的可见性，保留全部尺寸、底层色场和纸纹；正常目检截图保留完整前景。

Δ∞定义为两点RGB各通道绝对差的最大值，范围0–255；不是ΔE，也不是文字对比度。原始坐标、RGB、差向量与欧氏距离见[修复前](artifacts/before-samples.json)／[修复后](artifacts/after-samples.json)。

**实测限制必须说明：b42b92f已有横向羽化，贴边这4px跨度的基线差值本来就是0；修复后为0–1灰阶。不能把它写成“局部台阶从很大降为0”。本次用全幅图层范围、视口边缘开关对照和1920整屏截图共同验收：去除的是内容盒色场的构图边界。**
