# 个人站点参考与本轮取舍

观察日期：2026-10-25。以下来自各站点当前公开页面；属于内容与信息架构参考，没有复制其正文、素材或品牌。

## 别人的网站放什么

| 一手页面 | 观察到的内容与页面组织 | 适合小站的做法 |
| --- | --- | --- |
| [Maggie Appleton 首页](https://maggieappleton.com/) | 文章、零散笔记、设计模式、书库、近况、关于分别有入口 | 内容按阅读目的组织，不能为凑栏目编造内容 |
| [Maggie / Now](https://maggieappleton.com/now) | 按月份更新阅读、探索与思考 | 项目近况带核对日期，与长期自我介绍分开 |
| [Maggie / Colophon](https://maggieappleton.com/colophon) | 说明技术、内容编辑、字体和文章完成程度 | 增加“关于本站”，解释排版和本地数据边界 |
| [Brian Lovin 首页](https://brianlovin.com/) | 写作入口与多个独立项目；Stack、TIL 等也是可进入的内容栏目 | 把需要持续积累的内容放内页，首页只保留精选 |
| [Brian / Stack](https://brianlovin.com/stack) | 工具名称、一句话用途，以及筛选入口 | 技术清单说明具体用途，而不是列一墙 Logo |
| [Anthony Fu / Projects](https://antfu.me/projects) | 先给当前重点，再按生态和用途组织项目 | 项目数量增长后再增加分组，目前四件作品保留现有分类 |
| [Anthony Fu / Use](https://antfu.me/use) | 硬件、开发工具等分组，有用途或配置链接 | 未确认个人设备与偏好，因此本轮只展示已用于项目的技术 |
| [Lee Robinson 首页](https://leerob.com/) | 简介、主题笔记和长文入口 | 清楚的自我介绍和真实记录比增加装饰更重要 |
| [Josh Comeau 首页](https://www.joshwcomeau.com/) | 教程列表、分类与热门内容入口 | 有足够内容后再做专题和推荐，不编造“热门”数据 |

上表的取舍是针对本站的设计判断，不是参考站作者对本站的建议。

## 页面与技术怎么配置

Maggie 的 Colophon 明确说明使用 Astro、MDX、Vercel，并用文件维护内容；这些是她公开记录的技术。本轮没有根据网页外观猜测其他站点的框架。

有间小站继续使用现有原生 HTML/CSS/JS 和本地资源。参考别人的内容组织不要求采用同一框架、付费字体、托管平台或后台。

- 主导航继续为：首页、作品、文章、关于，另有搜索和联系入口。
- 新增一个 `workbench.html` 内页，合并近况、项目技术、更新记录和本站说明；用页内锚点浏览。
- 首页仅在原近况区增加工作台链接与日期。关于页和全站页脚也有入口，小屏可从页脚进入。
- 新内容接入全站搜索，搜索可直接跳到对应工作台小节。
- 数据在 `assets/workbench-data.js`，渲染在 `assets/workbench.js`，页内布局在 `assets/workbench.css`。
- 项目名称、状态与开发手记链接读取现有项目/文章数据；维护日期为人工核对值，不会自动伪装成当天更新。

## 本轮没有填入的东西

个人书单、设备清单、职业履历、学习成绩、技能评分、朋友链接都需要真实资料。订阅、评论和统计需要各自的数据处理方案；当前没有用空表单或虚假数字代替这些功能。

源码继续保存在私有仓库。没有启用网站公开托管，也没有把本地便签内容上传。
