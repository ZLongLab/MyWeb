## 开始前：不部署的手机接入方式

当前预览只监听电脑的 `127.0.0.1:4173`。手机自己的回环地址并不指向电脑；也不要临时换成普通局域网 HTTP 地址来代替 PWA 验收。

1. 保持电脑上的 `npm start` 预览运行。手机打开 USB 调试，经 USB 接到电脑，在手机上确认调试授权。
2. 电脑 Chrome 打开 `chrome://inspect/#devices`，找到真实手机，启用 USB 设备发现与端口转发：设备端口填 `4173`，电脑目标填 `127.0.0.1:4173`。
3. 在**手机 Chrome**打开 `http://localhost:4173/index.html`。本轮始终使用该地址来源，不要混用 `localhost`、`127.0.0.1`、其他 IP 或端口，以免切到另一份缓存／存储。
4. 先完成在线检查与安装，再做离线检查。离线阶段须断开 USB 或关闭端口转发，同时关闭手机 Wi-Fi 与移动数据，避免仍从电脑取到页面。
5. 所有点击、长按、滑动和主屏幕启动都在真实手机上操作。电脑远程调试只用于查看**该手机页面**的尺寸、缓存或错误；不要打开桌面设备模拟替代操作。

USB 转发方式依据 [Chrome 官方说明](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)。PWA 所需的安全上下文可由回环地址提供，参见 [MDN 安全上下文](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)。本清单不要求修改服务监听、部署网站或开启 Pages。`file://` 可用于本地浏览，但本站不在该模式注册 SW，不能用于本轮 PWA／缓存验收。

若手机不能建立连接、不能安装，先写下实际提示，相关项目记“未测／环境受限”，不通过部署、浏览器不安全开关或桌面测试补成通过。可先把清单复制到便签，方便断网时填写。
