日期：2026-10-28。用户要求把GitHub的提示词优化器部署到现有小站供其体验。

- 原项目：https://github.com/linshenkx/prompt-optimizer

## 运行与数据

主站`prompt-optimizer/`为独立应用，使用原项目的hash路由；相对资源路径适用于GitHub的`/MyWeb/`与Sites的根路径。工具内可返回小站。作品、工作台、搜索以及视频灵感室的链接指向同一个子目录。

公开构建不包含预设API密钥，`config.js`中的`window.runtime_config`为空。构建拒绝真实`.env`文件并清理继承的前端模型变量，不配置付费模型，不自动测试AI接口。访客通过模型管理自行选择服务、配置密钥。实际优化会向所选服务商发送输入，并可能收费；没有真实模型配置时，无法宣称已验证真实推理质量。

优化器沿用原项目的数据存储、收藏与备份机制，不读取视频灵感室的本地键，也不自动转移提示词。桌面尚未明确保存的输入不承诺刷新恢复；重要内容应保存收藏或导出备份。不同网址的数据分别保存。

## 构建与发布边界

构建工具Node24.22.1、pnpm10.6.1固定版本；只安装web/core/ui三个工作区所需依赖，使用锁文件且跳过依赖安装脚本。构建依次生成core、ui bundle和web，Vite base为`./`。没有安装Electron或下载模型。

主站保持81个运行文件、80项离线缓存；主站SW不把整个优化器加入预缓存。优化器自身SW作用域限定在`prompt-optimizer/`。发布包只复制校验过的编译产物与来源说明，共42个额外文件。禁止符号链接、环境文件、源码映射与不在许可扩展名中的文件；预览同样按清单提供文件。依赖、Git配置、个人浏览器资料不进入发布包。

GitHub Actions检出固定上游提交并重建，原站仍从同一小站仓库发布。ChatGPT Sites继续使用已有project_id与公开范围，通过官方源码同步／打包助手保存、部署。
