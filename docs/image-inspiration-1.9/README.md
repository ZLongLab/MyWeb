## 实现

- `image-prompts.html`、`assets/image-inspiration.css`：复用现有页面壳、主题、页脚和原生dialog；卡片明确显示示意标记，详情提供复制、收藏、归属及工具链接。
- `assets/image-inspiration-data.js`：五类各四个起点。每条有主体、场景、风格光线、构图、配色、注意事项、可用的视频模板编号及必要归属。
- `assets/image-inspiration-core.js`：组合文字、文本筛选、收藏备份验证及不丢失旧收藏的合并。`scripts/check-image-core.mjs`覆盖无效导入、重复／未知编号、版本错误、归属和跨模块编号有效性。
- `assets/image-inspiration.js`：用textContent创建卡片，不解释用户搜索为HTML。收藏只写`myweb_image_inspiration_v1`，格式为版本号和收藏编号数组；不读取优化器IndexedDB、API密钥、视频草稿或便签。每次写入前读取最新值，保留其他标签页的收藏。
- 损坏或不支持的本地数据不会被覆盖；浏览与复制继续可用。导入限制64KB，拒绝格式、版本或编号不正确的文件。导入只合并收藏，不替换已有收藏，导出仅包含本模块收藏编号。
- 详情有原生键盘焦点约束、Escape关闭、关闭后焦点恢复、只读可选择文字以及复制受限时的手动复制提示。没有通过新模型接口转发内容。
- 作品、工作台、全站搜索直接指向新页面；视频灵感室保留原有返回作品入口，并加图片入口。图片详情以新标签页链接到优化器及有效的视频模板，不自动传送内容，不覆盖已有草稿。
