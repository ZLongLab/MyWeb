- 个人设备、默认应用、书影音、照片及真实友链按站主选择留空；已确认的开发环境和设计参考明确注明来源，不编造个人偏好或关系。

## 维护与边界

原生 HTML/CSS/JS，无框架、构建或新增运行依赖。可选 Node 脚本负责快照和开放前产物，不是浏览网站的前置步骤。主题、季节与最近命令使用独立存储键，原有 `myweb_guestbook_v1` 的格式及导入导出逻辑未改动。

GitHub 连接器未提供贡献日历接口，因此维护脚本读取匿名公开贡献日历；只生成本地草稿，明确批准后才采用。页面仅读取批准的静态 JS/SVG，不读取令牌或私有仓库。

本轮未执行操作系统安装，没有手机／Safari实机安装验证，也未重复上一版的安装资格全套。没有发布网站、域名、目录登记、友链邀约或外发消息。

数字花园成熟度、双向链接、主题丛、关系图、关于页时间线留在1.1；RSS/sitemap/OG的正式接入、Now/Uses目录登记和webring留在开放阶段。

本轮使用 taste-design 完成视觉与交互实现。完整 feature-dev-loop 所需 Superpowers 配套在当前技能列表中缺失，因此没有启动完整控制器流程；使用现有浏览器、分工实现与可复核的定向验收完成此版。
