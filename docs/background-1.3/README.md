## 实际验收

- [437项矩阵检查](artifacts/matrix.json)：13页 × 纸／夜 × 春／秋 × 320／390／640／768／1024／1440，共312组布局；无横向溢出、可见操作区域不足44px、入场隐藏残留或脚本错误。104组全站八种外观的计算样式检查均通过。
- 同一104组还从实际合成的整页背景中抽样1400个文字片段，包含光晕、纹理、荧光笔与所在区块底色。临时隐藏真实文字再取样，并排除装饰图标、按片段实际文字色比较，避免把字形当作背景。保留每组最低的3项记录；这是抽样，不代表逐像素或读屏认证。
- 抽样发现夜色高光上的灰字偏淡后作局部颜色修正；只复核受影响的首页八种外观，其余已通过的96组与312组布局沿用完成记录，复核范围在JSON里注明。
- [71项定向检查](artifacts/checks.json)：内容差异边界、CSS预算、旧文件清理与截图忽略；八种光晕、夜色14星点、全页纸纹、无B2第三光晕、各页头渐隐／间距／透明度、纸色专属等高线、1023／1024水印断点、截图查看器与页脚点击层次、减少动态效果与打印。
