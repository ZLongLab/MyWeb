## C3 · 秩序

全站 `box-shadow` 声明仅使用 `none` 或以下三档变量；[源声明归并记录](artifacts/style-normalization.json)列出 26 处原手写值。输入框焦点改用 outline，避免把焦点环作为额外阴影档。

| 档位 | 用途 | 纸色值 |
| --- | --- | --- |
| `--shadow-near` | 卡片、小签、截图内部、按钮 | 0 1px 2px rgba(25,28,26,.06), 0 8px 20px -8px rgba(25,28,26,.14) |
| `--shadow-lift` | 书桌窗口、近况便签 | 0 2px 3px rgba(25,28,26,.1), 0 18px 34px -12px rgba(25,28,26,.26) |
| `--shadow-dialog` | 搜索、确认弹窗、大图查看器；登记为第三档 | 0 24px 64px rgba(25,28,26,.28)；夜色 0 24px 90px #00000066 |

常用过渡只用 200ms／300ms，缓动统一为 `cubic-bezier(.22,.61,.21,1)`。原生跨页转场出场 200ms、入场 300ms，房间方向保留。复制提示清空文字的等待同步到 300ms，避免淡出完成前文字消失。

≥1024px 页头使用 sticky、当前纸色 85% 不透明与 8px 模糊；滚动越过 24px 后高度 88→64px。同步补偿 24px 底部占位，文档起点仍为 88px，收紧时正文不跳动。文档滚动定位预留 64+28px，包含没有 id 的文章段落；2px 阅读进度线 z-index 100，位于页头 95 之上。[纸／夜滚动与定位检查](artifacts/behavior-checks.json)均通过。

### 保留的语义动画时序

这些是原有动画／停留时序，不作为新的常用过渡档位：

- 首屏入场 450ms，原有 0／80／160ms 错峰；高光 600ms、延迟 80ms；约 700ms 清理完成后交给书桌。
- 区块入场 500ms、原有 60ms 错峰；热力格生长 360ms、每周 8ms 错峰。
- 季节角标慢摆 6s；阅读进度由 scroll-timeline 驱动；键盘焦点环原有 150ms。
- 跑马灯 64s 线性循环；Logo 连点等待 300ms、门内问候停留 3s；复制提示停留 1.6s。

## C4 · 阅读

全站补齐 `-webkit-font-smoothing: antialiased`、`text-rendering: optimizeLegibility`，标题启用 `font-optical-sizing: auto`。桌面中文标题统一 `.02em`；纯英文标题标明语言，不套中文标题字距。正文行高不改，文章实际计算仍为 16px／33.6px／720px。[14 页计算样式记录](artifacts/probe.json)包含容器、标题字距与正文参数。

## C5 · 安静

- 跑马灯 40→64s，既有 motion.js 中用 IntersectionObserver 控制：默认暂停，进入视口运行，离开再次暂停；hover 暂停保留。
- 热力图首次进入视口才写入 sessionStorage 标记，同一会话刷新／返回不重播；存储不可用时保持静态。
- 书桌等待入场清理事件后接管；实测约 699ms。等待期间不写视差位移，聚焦窗口仍归零，减少动态时保持静态。
- 没有新增动画种类，也没有滚动轻视差。
