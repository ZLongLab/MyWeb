# 1.5.1 · 玄关构图修正

日期：2026-10-27。基线 `492307e` / `comfort-1.5.0`；恢复标记 `entrance-balance-1.5.1`。

站主截图指出首屏分布不舒服。原布局左侧文案顶对齐，右侧两张深色大窗口与便签叠放，造成右侧过重、左侧下方留白偏大。上一轮计算检查通过，仍没有解决这个构图问题。

本次只调整玄关桌面：

- 左右分栏 44／56 → 48／52，文案与右侧整体居中对齐。
- 主窗宽 88% → 78%，副窗 52% → 42%；副窗使用仓库已有的浅色 DocumentAssistant 截图，与主窗形成明暗区别。大图链接与对应截图一致。
- 便签从窗口上的叠放纸片改为下方流内信息条；移去桌面胶带和折角，保留暖纸底、陶土左界线与真实近况，日期使用现有 muted 文字色。
- 窗口舞台改为 384px，色卡高度 64→44px、印章 68→56px；1440px 实测整个首屏区块 712→664.89px，缩短约 47px。主窗遮挡约 14.3%，副窗低于 0.1%，便签为 0。

小屏原有样式保留；浅色副窗仅在桌面条件下选择，断点切换时保留窗口触发器焦点。未做手机或真机检测，没有修改文章版心、项目资料与全站配色变量。
