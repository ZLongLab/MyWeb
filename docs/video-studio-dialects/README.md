## 两套档案的规则原文

下列文字与 `assets/video-dialects.js` 中的 `rules` 数据一致。平台归类是写作预设，不代表实测的模型效果。

### 简派 · Seedance

1. 主体 → 动作 → 场景 → 镜头 → 风格，一段成文，不输出分段标题。
2. 保留填写的主体、动作、场景、镜头、风格；补充内容只提取结尾与首条关键约束，不展开分镜或后期。
3. 子句从简，合并换行；时长与画幅只作创作意图。

实现顺序为 `subject / action / scene / camera / look`。结尾补在动作之后；约束从补充内容中按原先顺序取第一条有约束语义的句子（`constraintLimit: 1`），不生成新的约束。已有的独立 S 编号长分镜及后期文字不塞进简派正文；它们始终保留在表单与草稿字段中，切回繁派可读。时长、构图在末尾标作创作意图。不做 AI 压缩或截断主体 / 事件。

“给 AI 完善”的简派引导原文：

> 请为 Seedance 完善以下自然语言提示词，保留主体、事件与结尾，仍用一段简洁文字，不新增故事事实。

### 繁派 · 可灵 / Sora / Runway / 通用

1. 先写总纲句，再依次输出场景与妆造、分镜序列、镜头语言、光影氛围、约束与后期；各段空行分隔。
2. 分镜沿用填写的 S 编号与时间轴；无分镜时只安排一个镜头，无时长时仅标 0 秒起、结束待定，不虚构剧情。
3. 运镜采用中文（English）对照；未知描述原样保留，不推断未填写的摄影动作。
4. 保留补充内容与后期事项；秒数是剪辑安排，不是平台参数或精确执行承诺。

分段数据的顺序为：

| 段名 | 内容 |
| --- | --- |
| 场景与妆造 | 已填主体、场景、构图；不猜测妆造细节 |
| 分镜序列 | 已有 `S01｜…` 等逐镜文字及其原时间轴；没有明示时间轴时按已填总秒数均分已有分镜，仅作剪辑安排；没有分镜时为 S01 一个镜头，不推断新的剧情或切镜 |
| 镜头语言 | 已填运镜、景别与角度；现有词库的英文术语加少量同义摄影表达对照，不改变词库文件，不添加未选择的运动 |
| 光影氛围 | 已填画风与光线；空白时提示待补充 |
| 约束与后期 | 原样保留补充字段，并说明精确卡点、字幕、声音、合成与入口能力需另核实 |

“给 AI 完善”的繁派引导原文（`{platform}` 替换为选中的平台名）：

> 请为 {platform} 完善以下自然语言分镜方案，保留主体、事件与结尾，每镜可独立复制，不新增故事事实。

所有秒数都是制作意图。缺少总时长时不擅自填 10 秒等默认值；S01 写“0 秒起，结束秒数待定”，后续已有镜头写“起止秒数待定”。未知摄影描述原样保留；已有中英对照不重复插入翻译。

## 存储与双向导入实测

存储键仍为 `myweb_video_studio_v1`；根数据与导出包装的版本号都仍为 1。新保存的每份草稿只新增 `platform`（`seedance / kling / sora / runway / generic`）；八个 fields 键、收藏和其余草稿字段均不变。

旧草稿缺少 platform 时，导入不补写、不迁移、不重组正文；点击“继续编辑”时选择器默认 Seedance，恢复原保存正文及输出类型。新版草稿重新打开恢复自己保存的平台和正文。

| 方向 / 异常 | 实测方法 | 结果 |
| --- | --- | --- |
| 1.10 → 1.12 | 使用真实旧版导出夹具，包含八个旧模板的收藏与草稿，逐个打开八字段及手动正文，再次导出 | 原样一致，重复导入不增加副本 |
| 1.12 → 1.11 | 在实际新版网页填写并保存 Sora 草稿与收藏，点击导出；导入本机保留的实际 1.11 构建 | 原正文、八字段、输出类型与收藏全部可读；旧版忽略未知 platform |
| 1.11 → 1.12 | 在实际 1.11 网页再次点击导出，导入干净的新版浏览器上下文，逐字段核对 | 数据形状与旧版导出一致；打开默认 Seedance，保留原先 Sora 正文，不强制重写 |
| 新版异常平台 | 在备份中先放合法新草稿，再放含 unknown 平台的草稿 | 整单拒绝，既有收藏与草稿不变，没有部分导入 |
| 同 id 不同内容 / 平台 | 新版浏览器用例及真实旧网页分别执行冲突导入 | 整单拒绝，不覆盖、不清空 |

兼容边界：1.11 不会保存它不认识的 platform。因此“新版 → 旧版再次导出 → 新版”保留正文和填写，但平台回到旧草稿默认值 Seedance。若把这份丢失平台字段的旧备份合并回同 id 的新版草稿，会按原有同编号差异规则整单拒绝；不会猜测或覆盖平台。以上均为隔离测试上下文，不读取或修改真实用户资料。

自动回归保留了一份基线 1.11 原校验器，`tests/fixtures/video-studio-1.11-core.txt`，由基线源文件直接复制；SHA-256 为 `0e4da121eb683027bfb6da5220686088c29e0e43d00c6df341829bf51fd2a7d3`。Playwright 的新版实际下载文件由此旧校验器读取，再导回新版；额外的新旧完整网页双向操作共 18 项检查通过，摘要见 `verification.json`。
