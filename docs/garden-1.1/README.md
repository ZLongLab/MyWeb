SVG 文件里的相对链接使用 ../../article.html，因为正式资源位于 assets/images/；内页使用同一生成数据构造内联 SVG，链接可附带来源上下文。这样 file:// 不需要 fetch，也能保留键盘、文字兜底和返回规则。
