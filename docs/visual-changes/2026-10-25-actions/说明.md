# 操作入口层级调整 · 0.13.1

针对首页“单调、按钮不明显”的反馈，聚焦操作入口，未增加栏目或运行依赖。

- 首屏：主按钮 56px 高、暖陶红实心；关于为描边次按钮，外部展示站保留轻链接。标题使用森林绿，近况便签加暖色层次。
- 作品：原详情链接内部增加绿色视觉按钮 span，不嵌套新交互元素；截图仍使用独立链接，“放大截图”放在画框底部，避免盖住界面。
- 区块：全部作品、全部文章与工作台入口使用明确底色和边框。
- 共用页头：联系入口改为浅绿底描边，未改变导航折叠断点。

## 验证

49 项浏览器断言通过，明细在 `checks.json`。覆盖 320/390/640/768/1024/1440 宽度的相关布局、导航宽度、入口尺寸、键盘焦点、详情与图片的不同动作，以及减少动态效果设置。正常页面未观察到脚本错误或资源失败。

五类主要入口的实际文字与背景颜色已测量，对比度均不低于 4.5:1；此结论仅针对记录中的入口组合，不表示已对全站做完整无障碍认证。
